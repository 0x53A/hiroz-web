No ROS installation or Python service is needed for this hosted two-window demo. The page may reload once to enable its WASM workers.

Connecting a real robot

Close the simulated device and point the groundstation at your robot’s router. Match its velocity topic/type, odometry, domain and namespace. Real navigation requires a running Nav2 server and the correct fixed frame; this demo does not install navigation on the robot.

The current transport uses rmw_zenoh. DDS-only robots need a compatible gateway; the ordinary zenoh-bridge-ros2dds protocol is not interchangeable. For remote routers from this HTTPS page, use a browser-trusted WSS endpoint. Plain WS to localhost depends on browser permissions.

Developing locally

Build this example, then serve its files using python3 serve.py 8083 or an equivalent HTTP server with COOP/COEP headers. This file server is only needed for local development, not for the hosted demo.
